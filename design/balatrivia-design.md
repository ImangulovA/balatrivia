# Balatrivia -- Design

Roguelike trivia in the spirit of Balatro. Open-ended questions are served one at
a time; over a run you clear escalating rounds by reaching a target of correct
answers, and between rounds you build a deck of jokers and consumables in a shop.
English language. Single player vs. the score.

Date: 2026-06-05

---

## 1. Stack & architecture

- **SvelteKit** + `adapter-static`, deployed to **GitHub Pages**. Fully client-side,
  no backend. (Same stack as the ru-catfishing project.)
- Run state lives in memory; meta (unlocks, high scores) in `localStorage`.
- Questions ship as a **static JSON bundle** generated by a Python build script.

### Data source
- Base: **OpenTDB** (CC BY-SA 4.0, commercial OK with attribution; ~5.3k verified
  questions; has `difficulty` + 24 categories).
- OpenTDB is multiple-choice, but we **use only question + correct answer** and play
  it as **typed open-ended input** (distractors discarded).
- Optional later layer: Jeopardy flavour questions (non-commercial only).

### Data pipeline (build time, `scripts/build_questions.py`)
Fetch/read OpenTDB -> `html.unescape` -> dedupe by normalized text -> generate
accept variants of the answer (normalization + aliases: drop articles `a/an/the`,
`&`<->`and`, digits<->number words, roman numerals, possessive `'s`) -> SHA-256 ->
write bundle: `{ id, category, difficulty, question, reveal(base64), accept[hashes] }`.
**No plaintext answers in the shipped source** (anti-cheat / anti-spoiler).

### Runtime modules (client)
- `norm.js` -- normalization, **byte-identical** to the Python `norm()`.
- `engine.js` -- run/round/economy state machine.
- `jokers.js` -- joker definitions as event hooks.
- UI in `+page.svelte`.

## 2. Run structure & round loop

- **Run** = escalating rounds. **8 rounds = win.** Lose a round -> run over
  (roguelike permadeath); meta unlocks persist.
- **Round** = fixed sequence of questions served one at a time (start: **5**).
  Each round has:
  - **Target** -- score points needed (escalates: 2 -> 3 -> 4 -> ...).
  - **Lives / strikes** -- allowed wrong answers; exceeding = run over.
  - Difficulty/category mix may skew harder in later rounds.

### Single-question loop
1. Show clue + category + difficulty indicator.
2. Player picks a **bet**: Safe / Double / All-in (availability gated by resources/jokers).
3. Type answer -> **submit (1 attempt)**. One attempt is the **base rule**; jokers
   may override it (e.g. Second Chance grants a retry).
4. `norm()` + accept-hash check -> correct/incorrect.
5. Jokers fire (`onCorrect` / `onWrong`), score points & money awarded, streak updated.
6. Reveal correct answer, advance.

### Scoring model (Variant 2: count + bets, NOT chips x mult)
- **Safe** correct = +1 point; wrong = nothing.
- **Double** correct = +2; wrong = -1 life.
- **All-in** correct = big boost / money; wrong = round ends immediately.

### End of round
- Reached target within lives -> **clear** + money reward (base + overfill +
  leftover-streak bonus).
- **Shop** -> spend money, then next round.

## 3. Shop & joker system (the build core)

### Shop (between rounds, Balatro-style)
- Offers **2-3 random jokers** + a consumable slot + **booster packs**.
- **Reroll** the offer for money (reroll cost rises each time).
- **Sell** a joker for a partial refund (rebuild your build).
- "Next Round" when done buying.

### Joker slots -- HARD CAP
- **5 joker slots, hard limit.** Buying at full slots requires selling one first.
- (Cap itself could later be raised by a rare joker/voucher, but 5 is the base ceiling.)

### Economy -- budget & prices
- **Starting money: $4.**
- **Money sources:** round clear base ($ per round) + leftover lives + streak length
  + target overfill.
- **Interest:** +$1 per $5 banked, capped at +$5/round (save vs. spend tension).
- **Joker prices by rarity:** Common **$4**, Uncommon **$6**, Rare **$8**,
  Legendary **$10**.
- **Sell value:** `floor(price / 2)`, min $1.
- **Reroll:** starts **$5**, +$1 per reroll within a shop visit (resets each shop).
- **Consumables:** ~$3 each. **Booster packs:** $4-6.

### Joker model (extensible, event hooks)
A joker is a set of hooks:
`onRoundStart`, `onQuestionShown`, `onBet`, `onCorrect`, `onWrong`, `onRoundEnd`, `onShop`.
This covers correct/incorrect amplifiers, rule overrides (extra attempt), category
bonuses. New enhancements get added here over time.

### Rarity
Common / Uncommon / Rare / Legendary -- drives price and spawn chance.

### Starter joker set (expand later)
- **The Historian** (C, $4) -- History questions give +1 point.
- **Cold Blood** (U, $6) -- first wrong answer each round costs no life.
- **The Underdog** (U, $6) -- correct hard answer gives +2 instead of +1.
- **Second Chance** (R, $8) -- grants a second attempt (overrides 1-attempt rule).
- **Dropout** (U, $6) -- after a wrong answer, next Double is free (anti-joker).
- **Streak Demon** (C, $4) -- streak 3+ -> each correct gives +$2.
- **Specialist** (R, $8) -- pick a category; in it, All-in costs no life on miss.

### Booster packs
- **Category Pack** -- open, choose 1 of 3 category-themed jokers.
- **Consumable Pack** -- consumables (Skip, Reveal-first-letter, Reroll-question).

## 4. Answer checking (reused from ru-catfishing)
- Python build script + JS `norm()` are **byte-identical**; accept-hashes shipped
  with the data.
- `norm()`: lowercase, strip parentheticals, strip non-alphanumerics, collapse
  whitespace, **collapse repeated chars** (typo tolerance), **sort words**
  (order-independent). English adaptation: strip leading articles, `&`<->`and`,
  numbers<->words, roman numerals, possessive `'s`.
- **One attempt per question** (base rule; perks may override).
